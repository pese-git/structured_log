Базовая библиотека, экосистема in-app просмотра логов и self-hosted
сервер, чтобы отправлять логи с устройства и читать их обратно. Три
строки, чтобы начать логировать:

<Code
	lang="dart"
	code={`import 'package:structured_log/structured_log.dart';

void main() {
  final log = getLogger();
  log.info('user_login', context: {'user_id': 42, 'ip': '127.0.0.1'});
}`}
/>

## Девять пакетов, одна система

Девять пакетов, сгруппированных по роли: библиотеки, встраиваемые в
приложение, self-hosted сервер и самостоятельный admin-клиент, который им
управляет.

<CardGrid stagger>
	<Card title="structured_log" icon="seti:dart">
		Структурированное JSON-логирование для Dart, чтобы каждая запись
		несла контекст, по которому можно фильтровать и коррелировать, —
		привязка контекста, типизированные correlation-поля, процессоры и
		маршрутизация по нескольким выходам. Без сторонних
		runtime-зависимостей, кроме `meta`. [Опубликован на
		pub.dev](https://pub.dev/packages/structured_log).
	</Card>
	<Card title="structured_log_flutter" icon="seti:flow">
		Постройте собственный in-app просмотрщик логов для Flutter, не
		привязываясь к одной дизайн-системе, — headless-ядро с ограниченным
		`LogBuffer`-sink, подключаемым к `structured_log`, и фильтрующим
		`LogViewerController`. [Опубликован на
		pub.dev](https://pub.dev/packages/structured_log_flutter).
	</Card>
	<Card title="structured_log_material, structured_log_fluent, structured_log_cupertino" icon="puzzle">
		Встройте готовый просмотрщик логов вместо того, чтобы писать свой, —
		три готовых к использованию просмотрщика поверх
		`structured_log_flutter`: Material 3, Fluent UI (в стиле WinUI) и
		Cupertino (в стиле iOS) — каждый с поиском, фильтрацией по
		уровню/категории и рабочим примером. Опубликованы на pub.dev.
	</Card>
	<Card title="structured_log_http" icon="rocket">
		Надёжно отправляйте логи с устройства на сервер — sink `HttpLogOutput`,
		доставляющий записи на экземпляр `structured_log_server` по HTTP:
		батчинг, retry с backoff, ограниченный буфер и `flushed` для ожидания
		доставки перед выходом. Пока не опубликован.
	</Card>
	<Card title="structured_log_server" icon="setting">
		Self-hosted, multi-tenant сервер, который принимает и хранит логи
		ваших приложений и позволяет искать их и следить за ними в реальном
		времени (SQLite или PostgreSQL) — группы, проекты, команды, секретные
		ключи, RBAC, квоты, retention и аудит-лог.
	</Card>
	<Card title="structured_log_admin_client" icon="laptop">
		Веб-приложение, в котором операторы и их команды ведут повседневную
		работу: вход, ролевой дашборд, управление ресурсами, поиск логов с
		живой лентой, управление пользователями и аудит-лог. Локализовано на
		английский и русский.
	</Card>
