Базовая библиотека, экосистема in-app просмотра логов и self-hosted
сервер, чтобы отправлять логи с устройства и читать их обратно.

## Быстрый старт

<Steps>

1. **Запустите сервер.** Поднимает `structured_log_server` и
   admin-клиент за одним nginx — больше ничего устанавливать не нужно.

   ```bash
   cd deploy && cp .env.example .env && ./deploy.sh
   ```

   Откройте `http://localhost:8080` и войдите с временным паролем,
   напечатанным в стартовом логе сервера (подробности:
   [Руководство администратора](/ru/guides/admin-guide/)).

2. **Создайте проект и секретный ключ.** В admin-клиенте: группа,
   проект внутри неё, затем секретный ключ для этого проекта — он
   показывается один раз, при создании (пошагово со скриншотами:
   [Руководство пользователя](/ru/guides/user-guide/)).

3. **Отправьте логи из своего приложения.**

   ```dart
   import 'package:structured_log/structured_log.dart';
   import 'package:structured_log_http/structured_log_http.dart';

   void main() {
     StructlogConfiguration.configure(sinks: [
       LogSink(name: 'server', output: HttpLogOutput(
         serverUrl: 'https://logs.example.com',
         projectSecretKey: 'slk_...', // из шага 2
       )),
     ]);

     getLogger().info('user_login', context: {'user_id': 42});
   }
   ```

   Записи появляются в живой ленте admin-клиента сразу же — без
   перезапуска, без опроса (подробности:
   [Руководство разработчика](/ru/guides/developer-guide/)).

</Steps>

		Структурированное JSON-логирование для Dart — привязка контекста,
		correlation-поля, процессоры, маршрутизация по нескольким выходам.
		Без сторонних зависимостей, кроме `meta`.
		[pub.dev](https://pub.dev/packages/structured_log).

		[pub.dev](https://pub.dev/packages/structured_log_flutter).
	</Card>
	<Card title="structured_log_material, structured_log_fluent, structured_log_cupertino" icon="puzzle">

	</Card>
