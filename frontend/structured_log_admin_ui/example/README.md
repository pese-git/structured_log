# structured_log_admin_ui_example

Component gallery for `structured_log_admin_ui`: most atoms, molecules and
organisms drawn with a few sets of parameters, in both themes (`AdminSearchPicker`
and `AdminAccountMenu` aren't wired into the gallery yet).

```bash
flutter run -d chrome
```

Live documentation rather than static screenshots — and the place to check a
component against the "Structured Log Admin UI" design canvas by eye.
