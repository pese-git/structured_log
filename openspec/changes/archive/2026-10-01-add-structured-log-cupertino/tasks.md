## 2. structured_log_cupertino (Cupertino-скин)

- [x] 2.1 Скаффолдинг пакета (`flutter create --template=package`): `pubspec.yaml` (зависимости: `flutter` sdk, `structured_log` `^0.2.0-dev.0+1` hosted, `structured_log_flutter` `^0.1.0-dev.2` hosted, `cupertino_icons` `^1.0.8`; `publish_to: none`; `uses-material-design: false`), `lib/`, `test/`; `LICENSE` скопирован; сгенерированные `.idea/`/`*.iml`/корневой `.gitignore` удалены (пакеты workspace их не хранят — единственный `.gitignore` для всего репозитория в корне)
- [x] 2.2 Встраиваемый виджет (`CupertinoLogViewer`): без собственной хромы страницы — тулбар (`CupertinoSearchTextField`, пауза/очистка через `CupertinoButton`), `LogCategoryFilterBar`, `CupertinoSlidingSegmentedControl` уровня (обёрнут в горизонтальный `SingleChildScrollView` на случай узких вьюпортов), список; `groupValue` сегмент-контрола вычисляется как индекс в списке из пяти опций (`null` = «All»), либо `null`, если текущий `levelFilter` не входит в этот список (иначе — рантайм-assert `CupertinoSlidingSegmentedControl`, т.к. её type parameter non-nullable)
- [x] 2.3 Полноэкранная обёртка (`CupertinoLogViewerPage`): тонкий `CupertinoPageScaffold` с `CupertinoNavigationBar(middle: Text('Logs'))` вокруг `CupertinoLogViewer`; кнопка «назад» при пуше — штатная для `CupertinoNavigationBar` (не нужна ручная `Navigator.canPop`-логика, в отличие от `FluentLogViewerPage`)
- [x] 2.4 Строка записи (`LogEntryTile`): цветная точка уровня, `event`, время, тег `category`; `showsDisclosureIndicator` — шеврон вправо на узких экранах (сигнализирует переход на новый экран), `selected` — тонировка фона на широких (запись показана в соседней панели)
- [x] 2.5 Фильтр по категории (`LogCategoryFilterBar`): горизонтально прокручиваемый ряд pill-кнопок (`CupertinoButton` с закруглённым фоном), варианты — уникальные значения `category` из буфера, плюс `allLabel` для «без фильтра»; скрывается при <2 категориях (аналог `LogCategoryChips`/`LogCategoryComboBox` двух других скинов, но не `CupertinoSlidingSegmentedControl` — тот не годится для динамического набора опций)
- [x] 2.6 Адаптивный детальный вид (`LogEntryDetailPanel` + логика в `CupertinoLogViewer`): один немодальный виджет содержимого (без ручки свайпа, без кнопки «Close» — в отличие от `LogEntryDetailSheet` у `structured_log_material`), переиспользуется в двух режимах — ниже брейкпоинта (`700.0`, по ширине самого виджета) тап пушит его в `CupertinoPageScaffold`/`CupertinoNavigationBar` через `CupertinoPageRoute`; на брейкпоинте и выше список (ширина `360.0`) и панель показываются рядом, по умолчанию выбрана самая новая запись
- [x] 2.7 Empty-state (`LogViewerEmptyState`) с двумя вариантами: «No logs yet» (без действия сброса) и «No logs match the current filter» (с кнопкой «Clear filters»)
- [x] 2.8 Тема — из `CupertinoTheme.of(context)`/`CupertinoColors.*.resolveFrom(context)` (светлая/тёмная); `logLevelColor` — общая с двумя другими скинами (см. раздел 1)
- [x] 2.9 Виджет-тесты на каждый сценарий из `specs/flutter-log-viewer-cupertino/spec.md` — 26 тестов в основном пакете (`cupertino_log_viewer_test.dart` — поведенческие на узкой ширине по умолчанию, `cupertino_log_viewer_responsive_test.dart` — брейкпоинт и master-detail на явно заданной ширине, `cupertino_log_viewer_page_test.dart` — только специфика страницы, `log_category_filter_bar_test.dart`), все проходят (`flutter test`). При написании обнаружены и исправлены два дефекта до коммита: (а) `CupertinoSlidingSegmentedControl` кидал рантайм-assert при `levelFilter` вне пяти известных опций — см. 2.2; (б) `find.text('protocol')` неоднозначен, когда и pill-фильтр, и тег категории строки списка показывают одинаковый текст — тесты скоупятся через `find.descendant(of: find.byType(LogCategoryFilterBar), ...)`
